# TypeScript Fundamentals

This project comes from [Mike North](https://github.com/mike-north)'s **TypeScript Fundamentals** course on [Frontend Masters](https://frontendmasters.com/courses/typescript-v4/).

I followed the lessons, wrote the exercises and notes as I went, and put this directory on GitHub to keep track of my progress.

## Contents

- [`notes-ts-fundamentals-v4/`](./notes-ts-fundamentals-v4): notes and code examples from each lesson
- [`welcome-to-ts/`](./welcome-to-ts): the first hands-on TypeScript project from the course
